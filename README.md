# پروژه آمار: بررسی سطح ویتامین D در بزرگسالان

این مخزن برای پروژه پنج‌فازی درس آمار تهیه شده است. داده‌های تحلیل از پیمایش ملی سلامت و تغذیه آمریکا، دورهٔ اوت ۲۰۲۱ تا اوت ۲۰۲۳، گرفته شده‌اند. همهٔ فازها از تعریف متغیرها و آماده‌سازی دادهٔ مشترک استفاده می‌کنند.

## پرسش پژوهش

سؤال اصلی پروژه، بررسی ارتباط فشار خون، مصرف سیگار، افسردگی، جنسیت، فعالیت بدنی و شاخص توده بدنی با سطح ویتامین D در بزرگسالان و سهم آماری آن‌ها در تبیین تغییرات است. برای متن دقیق سؤال فاز اول و جدول کامل متغیرها به `PROJECT_CARD.md` مراجعه کنید. در فاز دوم، برخی مؤلفه‌ها در قالب احتمال و توزیع‌های نظری تحلیل شده‌اند؛ این داده‌ها مشاهده‌ای‌اند و نتایج به‌تنهایی رابطهٔ علّی را اثبات نمی‌کنند.

## منابع و مستندات

- `PROJECT_CARD.md` — **کارت ادغام‌شده و کامل فاز اول و دوم**: سؤال اصلی، منشأ هفت فایل، جمعیت و حجم نمونه، جدول ۲۰ ستون، و تصمیم‌های روش‌شناسی.
- `data/README.md` — فایل‌های رسمی، شناسهٔ ادغام، قواعد بازسازی و محدودیت اشتراک داده.
- `requirements.txt` — کتابخانه‌های پایتون موردنیاز؛ بستهٔ خاص درس برای اجرای کامل فاز اول ممکن است جداگانه لازم شود.
- `reports/phase2/README.md` — راهنمای خروجی‌ها و محاسبات فاز دوم.

## فاز اول: تهیهٔ دادهٔ مشترک

فایل‌های رسمی زیر با شناسهٔ یکتای شرکت‌کننده ادغام شده‌اند:

`DEMO_L`, `VID_L`, `BMX_L`, `BPXO_L`, `SMQ_L`, `DPQ_L`, `PAQ_L`

شناسهٔ ادغام:

`SEQN`

خروجی تحلیلی فاز اول شامل ۶٬۳۳۷ بزرگسال و ۲۰ ستون است. برای تحلیل‌های اصلی ویتامین D در فاز دوم، ۵٬۸۲۴ مشاهده دارای مقدار معتبر و وزن مثبت استفاده شده است. فایل ساخته‌شده باید محلی بماند و در GitHub ثبت نشود.

پس از اجرای موفق نوت‌بوک فاز اول و ساخته‌شدن متغیر `final_data`، هنگام کار از پوشهٔ اصلی مخزن:

```python
final_data.to_csv('data/final_data.csv', index=False)
```

برای جزئیات بازسازی، به راهنمای پوشهٔ داده مراجعه کنید. کد فاز اول ممکن است برای منابع اولیه یا کتابخانه‌های درس به تنظیم محیط نیاز داشته باشد.

## اجرای دوبارهٔ فاز دوم

۱. در پوشهٔ اصلی مخزن، محیط پایتون و وابستگی‌ها را آماده کنید:

```bash
python -m pip install -r requirements.txt
jupyter lab
```

۲. مطمئن شوید فایل آماده‌شدهٔ فاز اول در محل زیر وجود دارد:

`data/final_data.csv`

۳. نوت‌بوک‌های داخل پوشهٔ زیر را به ترتیب اجرا کنید:

`notebooks/`

- `phase2_step1.ipynb` — احتمال‌های حاشیه‌ای، مشترک، شرطی، استقلال و قضیهٔ بیز.
- `phase2_step2_binomial.ipynb` — شمارش رویداد و مقایسهٔ فوق‌هندسی با تقریب دوجمله‌ای.
- `phase2_step3_normality.ipynb` — توزیع ویتامین D، چولگی، نقاط دورافتاده و تقریب نرمال.
- `phase2_step4_moments_covariance.ipynb` — امید ریاضی، واریانس، شاخص صفر و یک و کوواریانس با شاخص تودهٔ بدنی.

چهار نوت‌بوک از دادهٔ مشترک فاز اول استفاده می‌کنند. نمودارها در `figures/phase2/` و جدول‌ها و یادداشت‌ها در `reports/phase2/` ذخیره می‌شوند. برای ارزیابی محتوای نهایی از فایل `reports/phase2.pdf` استفاده شود. اگر PDF به‌صورت دستی اصلاح شود، باید با اعداد نوت‌بوک‌ها سازگار بماند.

## وضعیت پروژه

- فاز اول: نوت‌بوک و دادهٔ آماده‌شده موجود است؛ وجود و محل گزارش اصلی فاز اول در نسخهٔ آنلاین باید جداگانه تأیید شود.
- فاز دوم: چهار گام تحلیلی و گزارش تدوین شده‌اند؛ ثبت نهایی PDF، به‌روزرسانی مخزن و برچسب `phase-2` باید پس از کنترل نسخهٔ آنلاین انجام شود.
- فازهای سوم تا پنجم: در برنامهٔ پروژه هستند و خروجی نهایی آن‌ها در این مستند تأیید نشده است.

## نکتهٔ مهم دربارهٔ وزن خام و اصلاح‌شده

همهٔ ۶٬۳۳۷ مقدار ستون خام `WTPH2YR` از نظر عددی مثبت‌اند، ولی ۳۰۸ مقدار در حدود `5.397605e-79` بوده و در پایان فاز اول صفر شده‌اند. بنابراین ستون `WTPH2YR_clean` فقط ۶٬۰۲۹ وزن مثبت دارد؛ هر ۵٬۸۲۴ فرد با ویتامین D معتبر در گروه وزن اصلاح‌شدهٔ مثبت قرار دارد. کارت اولیه فاز اول این تمایز را نداشت و اکنون در `PROJECT_CARD.md` شرح داده شده است.

# فایل‌های گزارش فاز اول

نوت‌بوک تحلیل فاز اول در مسیر زیر قرار دارد:

`notebooks/phase1.ipynb`

این پوشه باید گزارش نهایی فاز اول و پیوست‌های مرتبط را نگه دارد. نسخهٔ PDF اصلی فاز اول در فایل‌های قابل بررسی فعلی تأیید نشده است؛ بنابراین در اینجا گزارشی ساختگی یا جایگزین تولید نشده است.

پیش از تحویل نهایی پروژه، وجود فایل زیر را بررسی کنید:

`reports/phase1.pdf`

اگر گزارش فاز اول با نام دیگری ذخیره شده است، پس از اطمینان از محتوای درست آن را در مسیر مقرر قرار دهید. تاریخچهٔ ثبت‌های قبلی GitHub نباید پاک شود.
